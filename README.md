# Simple Calculator Test Cases

## Project Overview
This project contains detailed manual test cases for a Simple Calculator Application written in Markdown format.

---

## Objectives
- Verify arithmetic operations
- Validate inputs
- Test error handling
- Verify BODMAS rule

---

## Features Tested
- Addition
- Subtraction
- Multiplication
- Division
- Decimal Inputs
- Negative Numbers
- Invalid Inputs
- Division by Zero
